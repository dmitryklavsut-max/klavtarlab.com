# klavtarlab.com — source

Static site, generated by `build.py` from `content.py` (EN / PL / RU copy, projects, client cases).

```
python3 _src/build.py .        # rebuild the site into the repo root
```

- Edit CSS, JS and images in `_src/assets_src/`; the build copies them to `/assets`.
- Hero chart data: `orders.json` — daily Etsy orders from ShopFlow analytics, 13.10.2025–12.10.2026.
- Contact form posts to `https://api.klavtarlab.com/lead` (Cloudflare Worker `klavtarlab-api`, source in `worker/`, data in D1 database `klavtarlab-leads`).
- To publish the hidden LEKS case, fill its entry in `content.py` and remove `"hidden": True`.
